# Plan: Every ADR this engine names in a consumer-read string says which package owns it

## Technical context

- Node ESM (`.mjs`, `"type": "module"`), Jest under
  `NODE_OPTIONS=--experimental-vm-modules`. No new dependency.
- The rule registries are plain arrays exported from `src/index.mjs`, one per module
  (`src/modules/*.mjs`). Each entry is `{ id, description, … }`.
- The scaffolder writes `_scaffold` notes into a contract document in
  `src/spec/scaffold.mjs`; `src/cli/commands/scaffold.mjs` drives a run.
- `docs/rules.md` is generated from the registries by
  `scripts/generate-rules-reference.mjs`; the `checks` job fails on a stale copy, so a
  `description` edit is incomplete until it is regenerated.
- `__tests__/helpers/synthetic-project.mjs` already builds a throwaway project a
  scaffold run can be driven against, so the note scan needs no new fixture harness.

## Design decisions

1. **One scan, in a helper, not three copies.** `__tests__/helpers/adr-citations.mjs`
   exports `unattributedAdrs(text)`, `citesAdr(text)` and `scaffoldNotes(contract)`.
   Every test that guards one of these surfaces imports it (FR-3), so widening the
   definition of a citation reaches all of them at once. This is the repo's own
   single-source rule applied to a test helper.
2. **The attribution is matched, not stripped.** The scan is a negative lookbehind for
   the owning package's name plus an apostrophe directly before the citation, accepting
   both `'` and `’`, and a word boundary before `ADR` so `GADR-1` is not a citation.
   Writing the owner's name is what fixes a finding; deleting the citation would pass the
   scan while losing the pointer, which FR-6's vacuity assertions exist to catch.
3. **Registries are found by shape.** The rule test collects every exported value that is
   a non-empty array of objects carrying a string `id`, rather than naming the registries
   (FR-4), so a module added later is scanned without touching the test.
4. **Notes are found by walking the document.** `scaffoldNotes` recurses the whole
   contract and yields `[jsonPointer, text]` for every string a `_scaffold` note carries,
   so a note at a new site, or one grown a second field, is still read (FR-5).
5. **The fixtures must reach every note site.** The note test asserts the pointers it
   found include each kind of site and that every note it read is a recognised kind, so a
   fixture that silently drafted less cannot make the scan pass over nothing.

## File structure

- `__tests__/helpers/adr-citations.mjs` — new; the one scan.
- `__tests__/helpers/rule-arrays.mjs` — new; `ruleArraysOf(index)`, the shape-based
  registry finder, shared with the rules-reference test.
- `__tests__/adr-citations.test.js` — new; the rule-description and scaffold-note guards.
- `src/modules/components.mjs`, `src/modules/coverage.mjs`, `src/modules/tokens.mjs` —
  attribute the seven rule descriptions (FR-1).
- `src/spec/scaffold.mjs` — attribute the `when` note (FR-2).
- `docs/rules.md` — regenerated (FR-7).

## Surfaces touched

- a published surface: a report shape — the rule `description` strings are read in
  consumers' reports and in `docs/rules.md`; `docs/rules.md` is regenerated by
  `node scripts/generate-rules-reference.mjs` and `--check` must pass
- a published surface: the CHANGELOG — a `fix:` entry, since the strings a consumer reads
  change
- `docs/report-structure.md` — it describes what a finding's message carries; check it
  does not quote an unattributed citation and update the passage if it does
- `docs/testing.md` — the test suite gains a file and `__tests__/helpers/` gains two;
  this doc is what `.prettierignore`'s carve-outs are kept in step with
- `docs/architecture.md` — no directory is added, removed or renamed, so nothing changes
  there; named here so the absence is a claim and not an omission
- none — no Routine, cron, workflow trigger or scheduled function changes, so there is no
  `cost` line: no new billed minutes
- none — nothing is installed on Chris's Mac, no plugin tree changes, no
  `_reusable-*.yml` body changes, and no required check name changes, so no ruleset edit
- none — this records no new decision: it restores citations to decisions already
  recorded, so `docs/adr/` gains nothing
